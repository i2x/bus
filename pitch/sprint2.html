ตอนนี้ยัง 1 node · สคริปต์แยก API + DB ไป node ที่ 2 พร้อมแล้ว

เทียบกับแบบ Sprint 0

  • แบบ: 2 subnet ใน VPC · จริง: ruk-com ไม่มี VPC แบบ AWS → ใช้ node ใน environment เดียวกันแทน
  • security group → iptables + bind private IP + ALLOW_FROM (กั้น 3 ชั้น)
  • Docker Compose → systemd (เครื่องเป็น Ubuntu พร้อมใช้)
  • Let's Encrypt → TLS ที่ LB ของ ruk-com

แยก node ยังไม่ได้ลองจริง — ยังไม่รู้ว่า container ของ ruk-com ยอมให้ตั้ง iptables หรือไม่ ถ้าไม่ได้ ยังเหลือ bind + ALLOW_FROM

สิ่งที่เรียนรู้

  • cloud ที่ได้จริงไม่เหมือนในแผน (ไม่มี VPC) → ต้องแปลง "security group" เป็นกลไกที่มี
  • กฎแต้มต้องอยู่ที่ server + DB constraint · หน้าเว็บแค่แสดง
  • เขียน test ยิง API จริง เจอบั๊กที่ curl มือไม่เจอ (race, ช่วงผ่อนผัน)
  • คำหยาบภาษาไทยไม่มีช่องว่าง → ต้องตัดคำ + รายการยกเว้น

ข้อจำกัดตอนนี้

  • ยังเปิดบัญชีทดสอบ (@example.com) คู่กับ Google จริง เพื่อใช้เดโม
  • ยัง 1 node · backup อยู่เครื่องเดียวกับ DB ถ้าไม่ได้รัน pull-backup.sh
  • word filter เป็นรายการคำ — คำใหม่ ๆ หลุดได้ ต้องพึ่ง report
  • ไม่รับรูป · ไม่มีแจ้งเตือนเมื่อรีวิวถูกซ่อน
