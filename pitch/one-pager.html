ระบบรีวิวและให้คะแนนรถโดยสารสาธารณะรายคัน ค้นหาด้วยเลขข้างรถ พร้อมระบบแต้มและ feed เพื่อจูงใจให้คนรีวิว

ต้นแบบค้นหา: i2x.github.io/bus

ปัญหา

  • ViaBus / แอป ขสมก. บอกตำแหน่งและสาย แต่ไม่บอกว่าคันนั้นแอร์หรือพัดลม รุ่นอะไร ค่าโดยสารเท่าไร
  • ไม่มีช่องทางประเมินคุณภาพการขับ: ขับหวาดเสียว ไม่จอดป้าย จอดกลางถนนส่งคน
  • ร้องเรียน 1348 ได้ แต่ผู้โดยสารไม่เห็นผล และคนอื่นไม่ได้ประโยชน์ ต่างจาก Grab / LINE MAN ที่ให้ดาวคนขับได้ทุกเที่ยว

ลูกค้า

  • ผู้โดยสารประจำ (กลุ่มหลัก) รู้ก่อนขึ้นว่าคันไหนดี มีที่สะท้อนปัญหาที่คนอื่นเห็นด้วย
  • ผู้ประกอบการเดินรถ (B2B, Phase 2) ได้ feedback รายคันแบบทันเวลา ใช้ประเมินคนขับ
  • หน่วยงานกำกับ (อนาคต) ได้ข้อมูลรวมด้านความปลอดภัยแยกสาย / เขต / อู่

โซลูชัน: ค้นเลขข้างรถ → รีวิวรายคัน → ได้แต้ม → แลกของ / feed

1. ค้นหาเลขข้างรถ ใช้ได้แล้วรุ่น สี ปี เขต อู่ ค่าโดยสาร (13 รุ่น 8 เขต)
2. หน้ารถ 1 คันคะแนนเฉลี่ย + แยก 3 ด้าน · รีวิว / แจ้งเหตุ
3. เขียนรีวิวดาว 3 ด้าน + ข้อความ + ป้าย/เวลา → +10 แต้ม
4. Feedใหม่ / ยอดนิยม / สายที่ติดตาม · แจ้งเหตุที่มีคนยืนยัน
5. แลกของสติกเกอร์ reaction · avatar · badge

ระบบแต้ม

เขียนรีวิว + ให้ดาว+10
ระบุป้ายและเวลาที่ขึ้น+5
มีคนกด "มีประโยชน์" (ต่อครั้ง, สูงสุด 30/วัน)+2
แจ้งเหตุที่มีคนยืนยัน ≥ 3+20
ถูก report และผู้ดูแลยืนยันว่าผิดกติกา−20

แลก: สติกเกอร์มีม 20–50 · avatar 60–100 · badge จากยอดรีวิว

กติกาและการป้องกัน

  • ต้องมีบัญชี · 1 รีวิวต่อคันต่อวัน · โหวตได้คนละครั้งต่อรีวิว (UNIQUE) · เพดานแต้มจากโหวตต่อวัน
  • รีวิว "คัน" ไม่ใช่ "คน": ห้ามชื่อ/รูปคนขับ · กรองคำหยาบ · ไม่รับรูปใน MVP
  • ปุ่ม report ทุกรีวิว · moderator ซ่อนและหักแต้มได้ · ทุกการเปลี่ยนแต้มบันทึกใน ledger
