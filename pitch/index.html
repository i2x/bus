Problem · Customer

ผู้โดยสารรู้ว่ารถอยู่ไหน แต่ไม่รู้ว่าคันนี้ควรขึ้นไหม

ปัญหา

  • ViaBus / แอป ขสมก. บอกตำแหน่งและสาย แต่ไม่บอกว่าคันนั้นแอร์หรือพัดลม รุ่นอะไร ค่าโดยสารเท่าไร
  • ไม่มีช่องทางประเมินคุณภาพการขับ: ขับหวาดเสียว ไม่จอดป้าย จอดกลางถนนส่งคน
  • ร้องเรียนผ่านสายด่วน 1348 ได้ แต่ผู้โดยสารไม่เห็นผลและคนอื่นไม่ได้ประโยชน์
  • บริการเรียกรถอย่าง Grab / LINE MAN ให้ดาวและคอมเมนต์คนขับได้ทุกเที่ยว รถสาธารณะที่คนใช้มากกว่ากลับไม่มี

ข้อมูลรถแต่ละคัน (รุ่น เขต อู่ ค่าโดยสาร) มีอยู่แล้วในวิกิพีเดีย แต่ยังไม่มีใครผูกกับ "ประสบการณ์ผู้โดยสาร"

Architecture

Two-Tier Network: web ใน public subnet · API และ DB ใน private subnet

องค์ประกอบ

  • Web tier (public): Nginx เสิร์ฟหน้าเว็บที่มีอยู่แล้ว + reverse proxy ไป API ผ่าน private IP
  • App tier (private): REST API Node.js/Express, JWT auth, กฎแต้มทั้งหมดอยู่ที่นี่
  • Data tier (private): PostgreSQL, backup รายวัน
  • NAT ให้ private subnet ออกไปติดตั้งแพ็กเกจได้ แต่ขาเข้าไม่มี

Stack

Docker Compose ต่อเครื่อง · deploy บน AWS VPC (2 subnet, 2 EC2) หรือ cloud อื่นที่มี VPC/subnet เทียบเท่า · frontend เรียก API ผ่าน /api ที่ origin เดียวกัน จึงไม่ต้องเปิด CORS

Security

เปิดสู่ Internet เฉพาะ 443 — ที่เหลืออ้างอิง security group ต่อกันเป็นชั้น

Security groupInboundจากเหตุผล
sg-web public443/tcp0.0.0.0/0ผู้ใช้เข้าเว็บผ่าน HTTPS
80/tcp0.0.0.0/0redirect ไป 443 และต่ออายุ cert เท่านั้น
22/tcpIP ทีมดูแลระบบ (ถ้าใช้ SSM ได้ก็ปิด 22)
sg-app private3000/tcpsg-webรับ request ผ่าน reverse proxy เท่านั้น
sg-db private5432/tcpsg-appเฉพาะ API ที่คุยกับ DB ได้

Outbound ของ private subnet ออกผ่าน NAT Gateway · NACL default deny ขาเข้าที่ไม่ตรงข้างต้น · ก่อนส่งงานจะ nmap จากภายนอกเพื่อยืนยันว่าเห็นแค่ 443/80

ชั้นแอปพลิเคชัน

  • Auth: JWT อายุสั้น + refresh token · รหัสผ่าน bcrypt
  • Input: validate schema ทุก endpoint · parameterized SQL (กัน SQL injection) · escape output (กัน XSS ในรีวิว)
  • Rate limit: ที่ Nginx และ API — กันสแปมรีวิว / brute-force login
  • Headers: HSTS, CSP, X-Frame-Options
  • Secrets: อยู่ใน env / secret manager ไม่อยู่ใน git
  • ข้อมูลส่วนบุคคล: เก็บแค่อีเมล+ชื่อแสดง · ไม่เก็บตำแหน่งผู้ใช้ · ลบบัญชีได้ · ไม่มีรูปคนขับ
  • Backup: DB snapshot รายวัน · log รวมที่ web tier
