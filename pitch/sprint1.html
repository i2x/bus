สิ่งที่เจอใน Sprint 1

  • ruk-com ไม่มี VPC/subnet แบบ AWS ตรง ๆ → จะใช้หลาย node ใน environment เดียวกัน (ยังต้องลองว่ากั้น traffic ได้แค่ไหน)
  • เลขข้างรถอย่างเดียวไม่พอ ต้องมีเขต UI เลยบอกให้เลือกเขตก่อนรีวิว
  • Rate limit ทำงานจริง: ทีมโดน 429 ตอนใส่ข้อมูลทดสอบรัว ๆ → ตอนทดสอบกลุ่มอาจต้องปรับ burst
  • LB ใส่ HSTS ให้อยู่แล้ว → header ซ้ำ ต้องเอาของ Nginx ออก (เรื่องเล็ก)
